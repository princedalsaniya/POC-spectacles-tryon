# POC - Virtual Spectacles Try-On

Virtual try-on POC using MediaPipe Face Landmarker. Users can see spectacle frames overlaid on their face via webcam in real-time.

## Tech
- MediaPipe Face Landmarker (browser-side, no server)
- Vanilla HTML/CSS/JS
- Static frame PNGs
- Hosted on GitHub Pages

## Usage
Open the site → pick a frame → allow camera → see it on your face.
